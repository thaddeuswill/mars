# mod/

The companion mod (NeoForge 21.1.x for Minecraft 1.21.1, Java 21, mod ID `mars`). Owner: Technical Lead.

Stage 2 slice 1 is built (planet values, Regolith Outgasser, Planetary Monitor): see [docs/tech/stage2-plan.md](../docs/tech/stage2-plan.md). Build plan: [docs/tech/build-plan.md](../docs/tech/build-plan.md); architecture in [ARCHITECTURE.md](../ARCHITECTURE.md); tests in [docs/tech/test-strategy.md](../docs/tech/test-strategy.md).

Art, sound, text, and datapack content do **not** go here: they live in `../pack/assets/` and `../pack/data/` and are copied into the jar at build time.
