# Reference photos (internal; not shipped in the pack)

Downsized copies (about 1000 px) of NASA/JPL-Caltech images, used only to audit our placeholder art against real hardware. Credit: NASA/JPL-Caltech. NASA media is generally not copyrighted (check NASA's media usage guidelines before using any of these outside this repo). Found through NASA's Photojournal catalog pages (`photojournal.jpl.nasa.gov/catalog/<PIA id>`), whose JPEG link points at `assets.science.nasa.gov`.

| File | What it shows | Notes |
|---|---|---|
| `PIA24201.jpg` | MOXIE twin unit during testing | Gold-plated box about 24 x 24 x 31 cm |
| `PIA24203.jpg` | MOXIE installed in Perseverance (top plate) | Gold plate, silver fittings, white tubes, Kapton-wrapped cable |
| `PIA19164.jpg` | Curiosity mast with a REMS wind boom | Cream-white painted mast, horizontal boom |
| `PIA22876.jpg` | InSight's first selfie (Dec 2018) | Clean solar arrays; used for colour measurement |
| `PIA25286.jpg` | InSight array after about four years of dust | Used for the dust look and colour measurement |
| `PIA18080.jpg` | Opportunity self-portrait after a wind cleaning (2014) | **False-colour version.** Used for layout only (rows of small cells); its colours are not real |

Colour numbers taken from these photos are approximate: the images carry their own white balance and processing (the 2022 InSight image is strongly orange).
