# Invented machines: look brief

**Owner:** Lead Artist · **Date:** 2026-11-27 · **Status:** design brief, no art made · **Serves:** `docs/design/world-and-blocks.md` 0.2 (make-it-work rule, item 5a) and 3.2 · **Real references:** `docs/science/machine-references.md` (SME; every source claim lives there, not here) · **Style base:** `docs/art/style-guide.md` sections 2, 2.4, 3, 3.1, 10

Scale: 1 block = 1 m = 16 px (1 px = 6.25 cm). **Real sizes:** the SME doc gives none for these machines (only InSight array 2.2 m, already built), so every size below is **invented for the game** and chosen to fit Minecraft block grids. Not verified against any real unit. Already modelled, skipped: solar array, battery, Outgasser, Oven, Oxygen maker, Monitor.

## 1. Shared rules (apply to all eleven)

**Palette (existing, style guide section 2):** alloy `#3B4148 / #59616A / #7E8790 / #A8B0B7` for bodies; safety orange `#E69F00` only on "touch this" parts (switch, hatch, intake); gold plating `#5C4320 / #7E5E2C / #A3823F / #C9AE6A` only where the reference is gold (atmospheric processor); salt-crust `#E7E2D6` for tubing; ice `#E4E8EA` for water parts; status lamp per 3.1 (square, hollow square, triangle, X). No vermillion `#D55E00` except on the emitter's hazard stripe (danger use, allowed by the reserved-color rule). No pure black or white. 16x16 textures; machines wider than 1 block use per-model textures sized to their footprint x 16.

**Game-invention cue (proposal, one for all):** the **made-up band**. A 2 px band along the bottom edge of every side face, in Fiction purple `#CC79A7` (dark edge `#8E3F6C`), drawn as a **dashed pattern, 2 px on, 2 px off**, plus a 4 x 4 px "made-up plate" on the front face next to the status lamp: `#CC79A7` square with a 1 px `#2A2420` diagonal slash. Why: purple is already the team's Fiction color (style guide contrast table; Fiction badge U-10), so the journal badge and the block match; the dashed band and slash carry the meaning by shape, so color is not the only signal (colorblind-safe); purple appears on no terrain, flora, fauna or other hardware, so it never reads as real. Real hardware (solar array, MOXIE gold box) never gets the band. Tooltip and journal carry the words "Game invention, not real" or "Game-sized version of a real idea" (world-and-blocks 3.2 labelling rule). Band stays purple through all dust stages (see dust rule). Mapped to U-10 so one icon family serves block, tooltip and journal.

**Dust weathering (shared, extends style guide 2.4):** machines weather on **top faces and the windward rim only**, never fully hidden. Four stages shared with the panel's cadence so the world reads consistently: 0 clean; 1 film (about 30 % of top-face pixels take bright dust `#B97C52`); 2 veil (top faces lifted a third to two-thirds toward `#B97C52`, rim at `#D09A6E`); 3 heavy (about 72 % of top pixels at dust, dark tan seams `#7A4530`). Intake grilles, lamps, the made-up band and the plate **never get dust** (they stay readable, 5:1 against dust) unless a machine's rule below says otherwise. Behavior per machine below; whether stages exist as separate models or as one texture overlay is a Technical Lead call (suggest one overlay texture per machine, 4 frames, to avoid 4x models).

**Silhouette test:** each must pass the 32 x 32 px solid-black test (style guide 3.2); the silhouette cue is listed first.

## 4. Assumptions and open questions

1. Sizes are invented, to fit the grid; nothing here claims real size.
2. Gate-priority column follows the block list "Why" column (world-and-blocks 3.2); the Game Designer confirms which are actual gates.
3. The made-up band uses Fiction purple; if the owner prefers a different cue, only section 1 changes.
4. Real-image use: NASA media guidelines checked before any image leaves the repo (SME note 6). Nothing downloaded.
