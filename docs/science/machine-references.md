# Machine references: the real thing behind every invented machine

**Owner:** Subject Matter Expert · **Date:** 2026-11-27 · **Rule served:** `docs/design/world-and-blocks.md` section 0.2 item 5a (every invented machine copies a real machine, instrument or plant) · **Related:** `docs/science/mars-materials-and-recipes.md` (invented-items table, section 2), `docs/art/references/README.md`

**How to read it.** "Real machine" is what the Artist and Designer copy. "Copy" is look, inputs, outputs, steps. "Must NOT claim" is the honest limit and goes in the journal label. **VERIFIED** = I opened the page this session (or, for MOXIE, the page recorded in the materials doc section 3) and quote a line. **NOT VERIFIED** = I could not open a source; treat as general knowledge. Sources are NASA Technical Reports Server (NTRS) abstracts fetched with `curl` into the scratchpad, HTML or JSON only read as text, never run. I read abstracts, not full papers. Nothing here was a source of numbers; all game amounts stay *invented*.

## 2. Short notes

1. **Strongest match:** ice extractor (Rodwell), carbon scrubber (CDRA), water reclaimer (ISS WRS), greenhouse (Veggie/APH), atmospheric processor (MOXIE/APM). Real hardware exists and a source line is open.
2. **Weak matches:** the **super-greenhouse emitter** and **mirror uplink** have no real machine. Per rule 5a the Designer should either keep them as plainly fictional (labelled, generic chemical-plant look) or replace them. I recommend the first, with the journal label already agreed in the materials doc.
3. **Soil treatment unit:** only the Phoenix wet-chemistry instrument is a real cousin, and it measured, not cleaned. Say so. Mark the machine "made up".
4. **Carbon scrubber honesty:** real CDRA sends CO2 on or overboard. "CO2 becomes carbonate rock" is the game's step (carbonate chemistry real, abundance NOT VERIFIED).
5. **Not opened, so NOT VERIFIED:** Honeybee ice drills, MARSIS, PIXL specifics, Mars drills' mechanics, ISS Sabatier hardware page (only a 2010 NTRS abstract was read), mirrors, super-greenhouse gases, battery packs. `www.nasa.gov` and `planetary.org` pages were not fetched: they are outside the allowed hosts for this task. `science.nasa.gov` mission pages for MOXIE returned 404.
6. **Images:** nothing downloaded. Existing repo photos cover MOXIE, InSight and Opportunity arrays only. The Artist needs new references for Rodwell, CDRA, WRS, Veggie/APH, TEGA, SHARAD. Credit NASA; check media guidelines before use outside the repo.
