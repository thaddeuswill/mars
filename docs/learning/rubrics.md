# Rubrics

**Owner:** Lead Instructional Designer · **Status:** Draft 1, 2026-11-26 · Used by: teachers (educator guide), the learning study (Stage 6)

Scored on written answers only (Keeper's Report reflections, final reflection, transfer task). Class discussion is formative and not scored. Each rubric is 1–4; the criterion in LEARNING.md 0.6 is **3 or higher**. The same rubric is used for both grade bands; HS answers are held to the HS descriptor where one is given.

Draft, to be checked against real student answers in the first playtest (score a sample with two raters and compare).

---

## D1: Argument about terraforming and existing life

Prompts: Keeper's Report 2, final reflection.

| Score | Descriptor |
|---|---|
| 4 | Takes a clear position, gives at least one reason based on something that happened in the game, **and** names what's at stake for the life already there. HS: also answers the strongest counter-reason fairly |
| 3 | Clear position with one reason based on the game, and names a stake for the life already there |
| 2 | Position with a reason, but the reason is general ("it's bad to hurt animals") with no link to the game, or the stake for existing life is missing |
| 1 | No clear position, or yes/no only |

Not scored: which side the student takes. There is no right answer (story rule 7).

## D2: Link to Earth

Prompts: final reflection, transfer task, any report answer that makes an Earth link.

| Score | Descriptor |
|---|---|
| 4 | Names a mechanism from the game (e.g. greenhouse warming, a feedback loop, photosynthesis) and correctly explains how the **same mechanism** works on Earth, with an Earth example. HS: also notes one way Earth differs from the game |
| 3 | Names a game mechanism and a correct matching Earth example |
| 2 | Mentions Earth, but the link is surface-level ("Earth also has air") or the mechanism is wrong |
| 1 | No Earth link, or a link that states a misconception (e.g. greenhouse effect = ozone hole) |

## B5: Unintended consequence

Prompt: Keeper's Report 2.

| Score | Descriptor |
|---|---|
| 4 | Names an unintended consequence, its cause, and the chain between them (at least one middle step). HS: also suggests how it could have been seen coming (e.g. on the Monitor) |
| 3 | Names an unintended consequence and its cause |
| 2 | Names a consequence but not its cause, or a cause with no consequence |
| 1 | None named, or names an intended result |

B5 criterion in 0.6 ("names one and its cause") = score 3 or higher.

## Transfer task: Earth's carbon cycle (B1, B2, D2)

Task: "Draw the feedback loops in Earth's carbon cycle. Label one reinforcing and one balancing loop."

| Score | Descriptor |
|---|---|
| 4 | At least 4 correct links with direction; one correct reinforcing and one correct balancing loop, each labeled; one sentence linking a loop to what happened on their Mars planet |
| 3 | At least 4 correct links; one correct loop of each type |
| 2 | Some correct links; only one loop type correct, or loop types swapped |
| 1 | Links mostly missing or wrong; no loop identified |

Scores feed three measures: B1 (links), B2 (loops), D2 (the Earth system itself). The SME must check the answer key before use.
